## Which file is which

From Mulberry Symbols, under the board word they picture (the Mulberry file
name in brackets where it differs): finished, get, go, good, help, i, in,
look, make, more, on, open, put, same, some, turn, up, want, what, when,
where, who, why, all (every), he (man - face), like (heart shape),
not (mistake no wrong), she (lady - face).

Drawn for Chorus: can, different, do, here, it, stop, that, you.

The pictures for the words of the ready-made boards (apple, bus, happy, jump
and so on) are all from Mulberry Symbols; `chorus_ui/symbols_src/mulberry/
SOURCES.txt` lists each board word with the Mulberry file it comes from.

## What was changed

Each SVG file was drawn as a PNG with a transparent background at 128, 256
and 384 pixels square (`2.0x/` and `3.0x/` hold the larger sizes), with the
empty margin trimmed and the picture centred with 6% padding. The Mulberry
drawings themselves were not changed. The first 23 Mulberry SVG files are
kept in `docs/brand/mulberry/` at the top of the repository; the other five,
and the eight drawn for Chorus, are in `chorus_ui/symbols_src/`, with the
scripts that draw the PNG files and the server's inline copies.

These PNG files are shared under the same licence, CC BY-SA 4.0.
